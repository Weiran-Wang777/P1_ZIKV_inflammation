# ZIKV-specific NF-κB/TNF inflammatory transcriptional signature in Huh7 cells

Re-analysis of public virus-inclusive single-cell RNA-seq (viscRNA-seq) data from Zanini et al. (2018, *eLife*), comparing host transcriptional responses to Zika virus (ZIKV) and dengue virus (DENV) in Huh7 cells.

**Target journal:** Emerging Microbes & Infections (EMI)

## Data source

- **Dataset**: GSE110496 (NCBI GEO)
- **Original publication**: Zanini F, Pu SY, Bekerman E, Einav S, Quake SR. Single-cell transcriptional dynamics of flavivirus infection. *eLife*. 2018;7:e32942.
- **Access**: https://doi.org/10.7554/eLife.32942

No new raw data were generated. This repository contains analysis code only.

## Environment

- R version 4.4.1
- Key packages: Seurat v5.1.0, dplyr, ggplot2 3.5.1, clusterProfiler, org.Hs.eg.db, patchwork

```r
# Install R dependencies
install.packages(c("Seurat", "dplyr", "ggplot2", "patchwork"))
if (!require("BiocManager", quietly = TRUE)) install.packages("BiocManager")
BiocManager::install(c("clusterProfiler", "org.Hs.eg.db"))
```

## Setup

1. **Reconstruct the processed Seurat objects from GEO.** Run `00_preprocessing.R` to download the raw count matrices from GSE110496 and perform QC, normalization, PCA, UMAP, clustering and cell-cycle scoring. This generates `data/denv_cc.rds` and `data/zika_clustered.rds`.

```r
source("P1_ZIKV_inflammation/00_preprocessing.R")
```

2. Run all downstream analyses with one command:

```r
Rscript run_all.R
```

## Reproducibility notes

- All scripts start with `set.seed(123)` for reproducibility.
- High-viral clusters are auto-detected (highest median viral_log), not hardcoded.
- Infection threshold: `viral_log > 0.5`.
- Cell cycle scoring uses Seurat's built-in human gene set (`cc.genes`).
- Pseudobulk analysis is **descriptive only** (no biological replicates available).
